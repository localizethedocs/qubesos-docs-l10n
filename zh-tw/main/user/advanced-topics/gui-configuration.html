GUI 組態

警告

此頁面適用於進階使用者。

高解析度顯示器的視訊 RAM 調整

當 qube 啟動時，會分配固定數量的 RAM 給稱為視訊 RAM 的圖形緩衝區。此緩衝區至少需要與整個桌面一樣大，考慮到所有已連接或將連接到機器的顯示器。預設情況下，它會分配目前顯示器和額外一個全高清（FHD）顯示器（1920×1080 8 位元/通道 RGBA）所需的記憶體。當機器的主顯示器為 FHD 解析度，且在啟動一些 qube 後連接了 4K 顯示器時，此邏輯會失敗。如果緩衝區太小，內部桌面調整大小就會失敗。

若要增加視訊 RAM 緩衝區的最小大小：

$ qvm-features dom0 gui-videoram-min $(($WIDTH * $HEIGHT * 4 / 1024))
$ qvm-features dom0 gui-videoram-overhead 0

其中 $WIDTH × $HEIGHT 是您預期需要的最大桌面大小。例如，如果您打算並排使用 1080p 顯示器和 4K 顯示器，則為 (1920 + 3840) × 2160 × 4 / 1024 = 48600，即每個 qube 略多於 48 MiB。進行這些調整後，需要重新啟動 qube。

在有多個不同方向的顯示器，或者您插拔顯示器的情況下，以下程式碼將使用 xrandr 設定正確的記憶體大小。

$ qvm-features dom0 gui-videoram-min $(xrandr --verbose | grep "Screen 0" | sed -e 's/.*current //' -e 's/\,.*//' | awk '{print $1*$3*4/1024}')

每個 qube 分配的記憶體量是以下各項的最大值：

  • gui-videoram-min

  • 目前顯示器 + gui-videoram-overhead

預設開銷約為 8 MiB，足以應付 1080p 顯示器（見上文）。因此，將 gui-videoram-overhead 歸零並非絕對必要；它只是避免分配不會被使用的記憶體。

緩解畫面撕裂的 Xorg 組態

如果影片播放不平滑而是斷斷續續的，這可能是因為 X 伺服器組態不當。如果您有 HD 顯示卡，可以嘗試將此組態放在 /etc/X11/xorg.conf.d/90-intel.conf 中，然後重新啟動 X 伺服器。

Section "Device"
        Identifier "Intel Graphics"
        Driver "intel"
        Option "TearFree" "true"
EndSection

GUI 疑難排解

如果 X 伺服器無法運作，您可以按下 Ctrl-Alt-F2 切換到另一個 tty。登入後，您可以檢查 Xorg 日誌檔案，並可能識別出錯誤。

請參見GUI 疑難排解，了解與 Qubes 圖形使用者介面相關的問題及其修復方法。
