螢幕擷圖

預設桌面環境是 Xfce4。

在此範例中，文書處理器在「work」:term:qube 中執行，該 qube 被分配了「藍色」標籤。它與其他 qube 完全隔離，例如用於隨機網路瀏覽、新聞閱讀的「untrusted」qube（分配了「紅色」標籤——「小心！」、「危險！」），以及用於非安全關鍵的工作相關網路瀏覽的「work-web」qube（分配了「黃色」標籤）。這些應用程式在不同的 qube 中執行，每個 qube 都有自己的 X 伺服器、檔案系統等。請注意標題列中不同的彩色邊框（標籤）和 qube 名稱。這些是由在 Dom0 中執行的受信任視窗管理器繪製的，在 qube 中執行的應用程式無法偽造它們。

Qubes 也可以無縫模式執行 Windows qube，整合到共同的 Qubes 可信賴桌面中，就像 Linux qube 一樣！（無縫 GUI 整合是在 Qubes R2 Beta 3 中引入的。）這需要先在 Windows qube 中安裝 Qubes Windows Tools。

Windows qube 與 Qubes OS 系統的其他部分完全整合：這包括諸如安全的、由策略控制的 qube 間檔案複製、剪貼簿，以及我們整個用於安全 qube 間 RPC 的彈性 qrexec 基礎設施！從 Qubes R2 Beta 3 開始，Qubes 也支援基於 HVM 的範本，讓您可以從範本立即建立許多具有共享「根檔案系統」的 Windows qube（您應確保您的授權允許在範本中進行此類作業系統實例化）。就像 Linux qube 一樣！

您始終可以清楚地看到某個視窗屬於哪個 qube。這裡可以立即看出密碼提示視窗屬於帶有「藍色」標籤的某個 qube。當我們查看標題列時，會看到「[qubes]」，這是實際 qube 的名稱。理論上，提示視窗下方的不受信任應用程式（此處為在 disposable 中執行的紅色 Tor Browser）可以在其內容中繪製一個類似外觀的視窗。在實踐中，這非常困難，因為它不知道例如正在使用的確切裝飾風格。然而，如果這是一個顧慮，使用者可以嘗試將更受信任的視窗移動到桌面上的空白區域，使其下方沒有其他視窗。或者更好的方法是，使用類似 Expose 的效果（可透過快速鍵使用）。來自不受信任 qube 的惡意應用程式無法偽造整個桌面，因為受信任的視窗管理器永遠不會讓任何 qube「擁有」整個螢幕。其標題列始終是可見的。

從使用者的角度來看，Qubes 完全著重於無縫整合。在這裡您可以看到它如何虛擬化來自其他 qube 的系統匣圖示。請注意網路圖示是紅色的。此圖示實際上由在單獨的 net qube 中執行的 Network Manager 管理。

所有網路功能都在一個特殊的、無特權的 net qube 中執行。（請注意上方畫面上 Network Manager 對話框周圍的紅色邊框，它反映了分配給 net qube 的顏色。）這意味著，如果您的網路卡驅動程式、Wi-Fi 堆疊或 DHCP 用戶端遭到入侵，系統其餘部分的完整性不會受到影響！此功能需要 Intel VT-d 或 AMD IOMMU 硬體（例如 Core i5/i7 系統）。

Qubes 讓您以集中方式一次更新所有 qube 中的所有軟體。這要歸功於 Qubes 獨特的範本技術。請注意，使用者不需要關閉任何 AppVM（qube）即可執行更新程序。這可以在之後的方便時間分別為每個 qube 進行。

Qubes 支援 qube 之間的安全文字複製貼上操作。只有使用者可以使用特殊的按鍵組合（Ctrl-Shift-C/V）啟動複製或貼上操作。其他 qube 無法存取剪貼簿緩衝區，因此它們無法從剪貼簿竊取資料。只有使用者決定應該允許哪些 qube 存取剪貼簿。（這是透過選擇目標 qube 的視窗並按下 Ctrl-Shift-V 組合鍵來完成的。）

Qubes 也支援 qube 之間的安全檔案複製。

Qubes' unique disposable qubes allow the user to open any file in a disposable in a matter of seconds! A file can be edited in a disposable, and any changes are sent back to the original file.

Qubes 提供了一個用於程式設計 qube 間服務的進階基礎設施，例如用於不受信任檔案的 PDF 轉換器（在`這篇文章 <https://blog.invisiblethings.org/2013/02/21/converting-untrusted-pdfs-into-trusted.html>`__ 中有所描述）。

Qubes 提供了一個專用的防火牆，它本身在隔離的 FirewallVM 中執行。
