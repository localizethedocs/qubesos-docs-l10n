介紹

什麼是 Qubes OS？

Qubes OS 是一款自由且開源、以安全為導向的單人桌面運算作業系統。Qubes OS 運用基於 Xen 的虛擬化技術，來建立與管理稱為 qubes 的隔離隔間。

這些 qube 以 虛擬機器 (VM) 的形式實作，具有以下特定屬性：

  • 用途： 使用一組預先定義的一個或多個隔離應用程式，用於個人或專業專案、管理 網路堆疊、防火牆，或滿足其他使用者自訂的用途。

  • 性質： 功能完整 或 精簡 的虛擬機器，基於主流作業系統，例如 Fedora、Debian、以及 Windows。

  • 信任層級： 從完全信任到完全不信任。所有視窗都顯示在統一的桌面環境中，搭配 無法偽造的彩色視窗邊框，使不同的安全層級一目了然。

備註

更多資訊請參閱 詞彙表 和 常見問題（FAQ）。

功能特色

強大的隔離能力

使用先進的虛擬化技術，將不同的軟體彼此隔離，如同它們安裝在不同的實體機器上。

模板系統

使用 應用 qube 共享根檔案系統，透過創新的 模板系統 而不犧牲安全性。

多作業系統

同時使用多個作業系統，包括 Fedora、Debian 以及 Windows

可拋棄式 qube

隨時建立 可拋棄式 qube，在關機時自動銷毀。

Whonix 整合

使用 Whonix 搭配 Qubes，在全系統範圍內安全地運行 Tor。

裝置隔離

透過隔離網路卡和 USB 控制器，實現安全的 裝置處理。

Split GPG

使用 Split GPG 來保護您的私鑰安全。

CTAP 代理

使用 Qubes CTAP 代理，讓您可以使用雙因素驗證裝置，而不會將您的網頁瀏覽器暴露給整個 USB 堆疊。

開放來源碼

使用者可以自由使用、複製和修改 Qubes OS，並且 鼓勵這樣做！

備註

鑑於 Qubes OS 的技術特性，先前具備 Linux 經驗會有所幫助。

為什麼選擇 Qubes OS？

實體隔離是數位世界所缺乏的既有防護措施

在我們的一生中，我們從事各種活動，例如上學、工作、投票、照顧家人以及與朋友聚會。這些活動在空間和時間上是受限的：它們彼此隔離地發生，各有其獨立的隔間，而這些隔間往往代表了一種基本的防護措施，投票就是一個例子。

在我們的數位生活中，情況則大不相同：我們所有的活動通常都在單一裝置上進行。這讓我們擔心點擊連結或安裝應用程式是否安全，因為一旦被駭，整個數位生活都將陷入危險。

Qubes 消除了這種擔憂，它允許我們將裝置劃分為多個隔間，就像我們將一棟實體建築劃分為許多房間一樣。更棒的是，它讓我們可以隨時建立新的隔間，並提供精密的工具來安全管理跨越這些隔間的活動和資料。

Qubes 讓您能夠將數位生活隔間化

我們許多人最初驚訝地發現，我們的裝置並不支援我們生活所需的那種安全隔間化，而且我們對軟體供應商依賴那些反覆被新型攻擊擊潰的通用防禦措施感到失望。

在打造 Qubes 的過程中，我們的基本假設是所有軟體都存在缺陷。不僅如此，在趕赴截止日期的匆忙腳步中，全球備受壓力的軟體開發人員正以驚人的速度產出新程式碼——其速度遠遠超過相對少數的安全專家能夠分析漏洞的速度，更不用說修復所有問題了。我們不會假裝能夠防止這些不可避免的漏洞被利用，而是基於它們將會被利用的假設來設計 Qubes。下一次零日攻擊只是時間問題。

面對這個發人深省的現實，Qubes 採取了一種極為務實的方法：限制、控制並遏制損害。它讓您可以將寶貴的資料與風險活動分開，防止交叉污染。這意味著您可以在同一台實體電腦上完成所有事情，而不必擔心一次成功的網路攻擊就將您的整個數位生活一舉摧毀。事實上，Qubes 相較於實體空氣隔離具有 明顯的優勢。

旨在同時支援弱勢使用者與進階使用者

Qubes 為弱勢及受主動攻擊目標的個人提供實用、可用的安全性，例如記者、社運人士、吹哨者和研究人員。Qubes 的設計理念認識到人會犯錯，並讓您能夠保護自己免受自身錯誤的影響。在這裡，您可以放心地點擊連結、開啟附件、插入裝置和安裝軟體。在這裡，您掌控您的軟體，而不是反過來被軟體掌控。（請參閱一些 不同類型使用者如何組織其 qube 的範例。）

Qubes 也非常強大。像 新聞自由基金會、Mullvad 和 Let's Encrypt 等組織，在建置和維護關鍵的隱私與安全網際網路技術時都依賴 Qubes，而這些技術每天又被全球無數使用者所依賴。著名的安全 專家 如 Edward Snowden、Daniel J. Bernstein、Micah Lee、Christopher Soghoian、Isis Agora Lovecruft、Peter Todd、Bill Budington 和 Kenn White 都使用並推薦 Qubes。

Qubes 是少數將使用者安全置於一切之上的作業系統之一。它現在是、也將永遠是自由且開源的軟體，因為構成我們數位生活核心基礎架構的基本作業系統必須是自由且開源的，才能值得信賴。
